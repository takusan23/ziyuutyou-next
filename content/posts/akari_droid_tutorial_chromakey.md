# 今回作る動画！
今回はスマホの画面があたかも透明に見える動画を作ります。特に難しくはなく、ほかのアプリにもクロマキー合成機能があればこれじゃなくても作れるはずです。

# 仕組み

![クロマキー合成のために単色](https://oekakityou.negitoro.dev/resize/02575911-3b69-4d8d-bb57-b00b9fa249a0.jpg)

`クロマキー合成`と呼ばれる技法？があります。`BB素材`のことです。  
これは動画の上に動画を重ねる際に、上に重ねた動画の特定の色を透かすことで、重なっている下の動画を見えるようにする技術です。

これを転用し、スマホのホーム画面の色を特定の色で塗りつぶすことで、その色を動画編集で透かせて、あたかもスマホの画面が透明になっているかのように見せることができます！！

# 手順
大まかな手順です。

- クロマキー合成をするための動画を撮影する
- アプリを入れる
- プロジェクトを作る
- 動画を追加する
- クロマキー合成を適用して、色が透けるようにする
- 時間を調整
- ほぞん！

# クロマキー合成の動画を撮影する
2パターンあると思います。

![背景も単色にする](https://oekakityou.negitoro.dev/resize/2814a629-357e-4d27-a9c4-6656f12c139f.jpg)

![スマホ有り無しを撮影する](https://oekakityou.negitoro.dev/resize/2f6abedc-e82f-4904-9b1c-dcd918ccb432.png)

1つ目が、スマホの壁紙と、スマホを撮影する背景を同じ色にして撮影する方法です。  
これは小物を撮影する撮影スタジオとか、クロマキー合成の背景になりそうな壁があればできます。スマホの壁紙とスマホの背景の両方が透けるため、どの動画を下地においても適用できます。  
デメリットは背景も同じ色にしないといけない点。

2つ目が、スマホなしの動画を撮影した後、単色の壁紙に設定したスマホを重ねて撮影する方法です。  
これはスマホの壁紙を単色にするだけで済みます。デメリットは、背景はスマホあり+なしの動画を撮影する必要があります。また、透けるのはスマホの画面だけになるので、背景を変えたい場合は撮り直しが必要です。

# プロジェクトを作る
アプリを起動して、新しいプロジェクトを作成します。適当な名前を付けて完了してください。

![新規作成](https://oekakityou.negitoro.dev/resize/00cd9ce8-6020-4e92-bf1d-043973effbf9.png)

次に`動画情報の編集`が表示されます。ここで、動画を保存するときの縦横サイズを決めます。特になければは先ほど撮影した動画と同じサイズにします。  

![動画の縦横サイズを決める](https://oekakityou.negitoro.dev/resize/046bb3e8-ea2c-471f-a54c-0fea237acadb.png)

`フルHD`の場合は`1920`と`1080`を入力します。  
`4K`の場合は`3840`と`2160`を入力します。  
すいません、まともな`UI`を作ってないため自分で入力させています、すいませんん、また、縦動画のために縦横を入れ替える機能も作ってませんでした。  
よって、縦動画の場合は↑の縦横の数値を入れ替えてください。優しくない`UI`ですいません。

また、`HDR`かどうかは撮影した動画次第では設定が必要なのですが、後で設定できるようになっています。分かる場合は今設定してもよいです。  
そして`完了`を押します。

間違えて閉じてしまった場合は、左上のメニューを押して`動画情報の編集`を選択すれば開くことが出来ます。

# 動画を追加する
`縦画面、横画面`の場合は下に表示されている追加ボタンを押して、`動画`を選びます。  
`タブレット、折り畳みスマホの展開時`は、右上のボタンから`タイムラインへ追加`を押して`動画`を選びます。追加したら`ボトムシート`が表示されますがいったん閉じてよいです。

![スマホのメニュー](https://oekakityou.negitoro.dev/resize/041c125e-e6dc-46b4-8f84-7ce3fabf04eb.png)

![タブレットとか折り畳みの時のメニュー](https://oekakityou.negitoro.dev/resize/0b90ab7e-4a01-4aaa-a5fd-eb3ad30b1ca4.png)

動画ピッカーが開くのでここでさっき撮影した動画を選びます。  
もしスマホの壁紙とスマホを撮影する背景の色が同じで撮影した場合は、先述の通り重ねてる下の動画は好きな動画にできます。  
一方、スマホの壁紙のみを単色にした場合は、下の動画に重ねる動画はスマホ抜きの動画を選ぶ必要があります。

まとめて追加する機能が現状ないため、一つ目の動画を追加したらもう一度追加ボタンを押して二つ目の動画を追加する必要があります。

## 追加する別の方法
ドラッグアンドドロップすることもできます。  
`Google フォト`とかなら写真・動画を長押しすると移動出来て、このアプリの下半分まで持ってきて離すと追加できます。ドラッグ中は下半分がピカピカします。

# 画面の説明

![スマホ](https://oekakityou.negitoro.dev/resize/1e615150-6be2-472d-b264-cea6ca1a1848.png)

![タブレット](https://oekakityou.negitoro.dev/resize/01beb821-3e0d-4c07-b2fe-8797b8f2caf6.jpg)

スマホの縦画面の場合は、上半分が`プレビューと位置調整`、下半分が`タイムライン`になります。  
スマホが横画面の場合は、左半分が`プレビューと位置調整`、右半分が`タイムライン`になります。

そしてタブレット、折り畳みスマホ展開時は、左上が`プレビューと位置調整`、右上が`メニュー兼追加`になります。メニューが常に表示されるため、スマホ縦横画面にあった左上と中央下のメニューボタンは表示されません。  
そして下半分を占める`タイムライン`で構成されています。

詳しくは必要になったら！別に難しくはないハズ！

![サイズ変更後](https://oekakityou.negitoro.dev/resize/2049c799-be47-4460-a90d-9bb7e6357f1e.png)

そのため、タイムラインもしくはプレビュー（もしくはメニュー）の表示割合を調整する機能があります。パソコンみたいに`ドラッグ`操作でそれぞれの`UI`の大きさを変えられる機能です。

タイムラインとプレビューの間にある`タイムラインメニュー`を押して、`サイズ変更機能を有効にする`を選びます。  
これで、それぞれの`UI`の教会に何やら掴めそうな棒が表示されます。これをドラッグすることで、プレビューやタイムラインの表示割合を自由に変更できます。

## タイムラインを操作する
先述の説明より、**タイムライン**を見てください。  
動画を追加したので、追加した分だけ`動画`と`音声`が追加されていると思います。

タイムラインと聞いて、`AviUtl`とか`ゆっくりムービーメーカー`を想像した皆様、それと全く同じものです、頑張ってそれっぽく作りました。  
もう説明は不要そうですね。

そうでない方向け、  
タイムラインは、動画に表示・再生したい`動画`、`音声`、`画像`、`文字`、`エフェクト`を配置する場所です。  
これは上下左右のスクロールできます。

まず左右方向。これは時間です。  
一番左が`0秒`になり、右に行くほど時間が進みます。上に時間が表示されるので、どの時間に表示したいかはここを見て配置します。

上下方向にもスクロールできます。これは、動画に同時に`動画`や`音声`、`画像`、`文字`、`エフェクト`を表示するためです。同じ時間の縦に並べる感じ。  
ほかの動画編集アプリでは`PinP (ピクチャーインピクチャー)`とか言われている機能は、ここでは縦方向に並べることと同義になります。  
下方向につれて上に重ねて表示されます。`PowerPoint`的な言い方だと`0`が最背面、`20`が最前面になります。

動画の再生位置を変えたい場合は、タイムラインに表示されている動画をドラッグすればよいです。  
また、動画の`X/Y`位置を変えたい、複製したい、削除したい場合は、その動画を押すことでコンテキストメニューが表示されます。

また、赤色の縦棒があります。これは今の再生位置で、これを動かすと、上か左のプレビューがその位置の動画のプレビューになります。  
これとは別に青色の縦棒が出ていることかもしれません。これは動画を保存するときの時間になります。  
ほかの動画編集アプリによっては一番最後の動画の時間に自動で設定されることがありますが、このアプリでは手動で設定する必要があります。後で説明します。

（つまり`AviUtl`を使ったことがあれば一度はやらかすであろう？、**ダーク尺余り**を引き起こす可能性を同じく抱えていることになります）

## 動画を間違えて追加した
タイムラインの動画をおすと、コンテキストメニューが表示され、`削除`を選ぶことで間違えて追加した動画を削除できます。  
同様に音声も消しましょう。

## タイムラインの上にある UI
`タイムラインメニュー`から、`複数選択`モードに切り替えたり先述の通りサイズ変更を有効にできたりします。  
今回はそこまで使わないので省略します。

タイムラインの右上にある虫メガネのアイコンを押すことで、タイムラインの拡大縮小が出来ます。
カーナビみたいですね。

虫メガネの隣が`戻る・進む`ボタンです。  
パソコンにもあると思いますがそれと同じです。一個戻すと、戻すのをやめるボタンです。

# 位置と時間を合わせる

![タイムライン](https://oekakityou.negitoro.dev/resize/1e615150-6be2-472d-b264-cea6ca1a1848.png)

![タイムラインの動画を押して値の編集を押す](https://oekakityou.negitoro.dev/resize/3070206c-4b94-4b41-bb2c-543f56b49aa5.png)

![値の編集](https://oekakityou.negitoro.dev/resize/01e691ca-8409-488f-9675-7c9822a37459.png)

位置がずれてます。タイムラインにある動画素材を長押しして、1番目と2番目の動画の位置と時間を合わせます。  
音声も同様に動画に合わせます！

タイムラインの動画で、左の位置が同じになっていれば同時に表示されます。今回はクロマキー合成しかしないため、`0秒地点`にそろえています。  
マグネット的な機能があるので、左の位置を同じにするのはそこまで難しくないはずです。

次は位置を合わせましょう。  
タイムライン上の動画を押します。コンテキストメニューが表示されるので、`値の編集`を選びます。

すると、スマホでは`ボトムシート`、タブレット等の場合は上に重なる画面が表示されるはずです。  
ここの、`X座標`、`Y座標`を`0`にすることで、動画がずれずに目いっぱい表示されるはずです。もしそうではない場合は、多分プロジェクトを作った時の動画縦横サイズが違う可能性があります。。。  
メニューより、`動画情報の編集`を選ぶことで、動画の縦横サイズを再設定できます。

# 10 ビット HDR の警告が表示された

![この動画は10ビットHDR動画が何とかかんとか...](https://oekakityou.negitoro.dev/resize/01e691ca-8409-488f-9675-7c9822a37459.png)

大丈夫！！！！このアプリは`10 ビット HDR`に対応しています。が、デフォルトでは`SDR`なので、プロジェクトの設定を変更する必要があります。

というわけで`動画情報編集画面を開く`ボタンを押して、`HDR`の設定を押します。  
で、ここで`HDR 動画`の種類を選んでください。  

・・・が、カメラアプリによっては、どの種類の HDR 動画を利用しているか、を表示してくれないアプリがあります。

![HDR動画の種類を選ぶ](https://oekakityou.negitoro.dev/resize/12e62ac4-53d5-4930-adcc-cfd872e987b6.png)

なので、少し下にスクロールして`動画を選択`ボタンを探してください。  
これは動画ファイルから`HDR`の種類を特定し設定してくれます。もちろん`HDR`の種類を覚えている場合は、選択肢を選んでも大丈夫です。

選べたら閉じて、`完了`を押しましょう。

# プレビューを動かして大体できているか確認する
タイムラインの何もない空いている箇所を押すと、赤色の縦棒がタッチしたところに移動してきます。これがプレビューの位置で、プレビュー画面に表示されるはずです。  
何回か動かしてみてきれいに透けていたらおめでとう！！  
もしうまくいかなかった場合は`値の編集`からクロマキーの設定をやり直してみてください。。。

また、今回は使いませんでしたが、`プレビュー`のモード切り替えが出来ます。  
`再生ボタン`と`指のアイコン`が横に並んでいるボタンがあるのですが、これを`再生ボタン`の方にすると動画プレイヤーみたいな見た目になって、最終チェック的なことが出来ます。

## 有識者向け 詳細設定
![エンコーダー詳細設定](https://oekakityou.negitoro.dev/resize/219ac699-fdbe-4041-8d78-5efcfb536279.png)

もし、`動画のコーデック`を変更したいとか、`フレームレート`を変更したい場合は、`手動で設定`を選んでください。  
基本はアプリの中に入っている固定値を使いますが、書き換えたい場合は！

基本は上級者向け機能です。たとえば、`HDR`動画を保存する場合は`H.265 (HEVC) コーデック`を利用します。世の中のカメラアプリがそうしているためです。  
しかし、いざ`Windows`で再生しようとなると`HEVC ビデオ拡張機能`とかいうよくわからん`120円`のアプリを買わないといけない？？とかだったはずです。  
それが嫌な場合、もう1つの選択肢である`AV1 コーデック`を手動で選ぶということが出来ます。  
（ただし現状`Google Pixel`以外は`AV1 ハードウェアエンコーダー`がなく、`CPU`を使うしかなくめちゃめちゃ保存が遅いです・・・）
